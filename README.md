# RNCAN_crown_segmentation

Ce projet effectué dans le cadre du cours GLO-7030 - apprentissage par réseau de neurones profond visait à segmenter des couronnes d'arbres à partir d'images multispectrales. Notre code utilise [TreeCountSegHeight](https://github.com/sizhuoli/TreeCountSegHeight) comme base.
Certaines modifications ont été apportées, notamment pour modifier les chemins des fichiers à utiliser, les configurations du module et les paramètres d'entraînement.
Pour réussir l'entraînement, les instructions fournies par _TreeCountSegHeight_ doivent être suivies. Nous avons également détaillé les étapes que nous avons suivi pour l'entraînement dans Instructions_v3.docx.

Des notebooks Jupyter sont également fournis pour faciliter le traitement des données et l'analyse des résultats.
Bien que _TreeCountSegHeight_ fournisse son propre fichier `requirements.txt`, nous en avons ajouté un autre dans le dossier racine, principalement pour les notebooks.
