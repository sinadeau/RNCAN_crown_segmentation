# GLO-7030_Projet-NRCAN-Lidar

Le code du projet utilise [TreeCountSegHeight](https://github.com/sizhuoli/TreeCountSegHeight) comme base.
Certaines modifications ont été apportées, notamment pour modifier les chemins des fichiers à utiliser, les configurations du module et les paramètres d'entraînement.
Pour réussir l'entraînement, les instructions fournies par _TreeCountSegHeight_ doivent être suivies.

Des notebooks Jupyter sont également fournis pour faciliter le traitement des données et l'analyse des résultats.
Bien que _TreeCountSegHeight_ fournisse son propre fichier `requirements.txt`, nous en avons ajouté un autre dans le dossier racine, principalement pour les notebooks.
